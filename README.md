一切的起因是作者的老师以“信息化教育”知名推行了“四人小组”制，要求我们记录自己的作业扣分、记录扣分，互相竞争。不可否认的是这个制度的确富有成效，但是管理分数的重担便推到了我们电教身上。  
既然是“信息化教育”，索性就应该有更加智能的方式管理，因此便有了此程序：学生分数管理器(StudentScoreManager)。

使用方法
---
~~懒得放图了下次再放hhh~~  
1. “班级信息”用于编辑表格显示的学生名称，按“新建”可以创建一个“组”，点击组的名称可以编辑“组”的同学名称（注意：受限于技术原因，编辑功能“外包”给了当前系统的文本编辑器，当打开时会同步打开一个指定的弹窗用于同步信息，请一定要在您编辑完成并保存之后再按此弹窗的“确定”，不然会导致信息不同步！）（每行一个），“上移”可以移动你按下的那个表和上面一个表，“删除”如字面意思；
2. “选择表格”可以实现对表格的文件创建与编辑，基础功能与上述“班级信息”一直。除此以外还有一个“选择”，可以选择你要处理的表格；
3. “编辑表格”可以展示与编辑表格。展示顾名思义，如果不理解的话可以查看图例。编辑需要你点击具体的列，便会进入一个针对该项的编辑界面；
4. “分数总览”可以查看当前选中表格各组的总分，有多重排序方式。

文件
---
软件的文件存放在目录的"Data"文件夹下。  
"Data/Settings"用于存放用户的设置，具体内容参见仓库"/docs/dev/setting_list"文件。  
"Data/0/"用于存放班级的文件 ~~（原本计划设计“多班级”功能的，最后流产了……）~~，共有两列文件：
1. ".ssdata_names"文件用于存放学生姓名，每个文件存放一“组”；
2. ".ssdata_event_table"存放事件表格，每行一个事件，具体格式为：学生名称 分数 时间（当前时区） 标记（参见"student_score_data.hpp"） 列（0开始） 标记（可有可无）

移植？
---
如果您想要移植到Linux/MacOS上，请为sys_api.cpp编写对应的实现，并且完成主文件的#if的平台对应；  
如果您想要移植到安卓/iOS上，请在完成上一条提到内容的基础上给raylib_obj_ex.cpp的按钮逻辑进行修改以适配多点触控 ~~（或者不加）~~，并且最好增加一个屏幕键盘。
